Platform Administrator

Platform administrators carry organizor-admin in the platform realm. They operate across tenants from the platform control plane.

They can create catalog tenant records, run full onboarding, upgrade tenant databases, soft-delete tenants, hard-delete previously soft-deleted tenants, manage tenant plan defaults and module entitlements, install or disable tenant modules, edit tenant config overrides, and manage tenant users for a selected active tenant.

Tenant Administrator

Tenant administrators carry tenant-admin in their own tenant realm and must match the tenant selected by X-Tenant-Slug.

They can manage tenant users, config inspection, people, relationships, organizations, activity setup, registrations, document capability assignment, and their own profile actions. They cannot list/read the platform tenant catalog, alter a plan entitlement, or manage module installation lifecycle; enabled modules may delegate only their typed settings to tenant administrators.

Tenant User

Tenant users carry tenant-user in their own tenant realm and must match their tenant. They do not use the Organizor portal; profile display, password-change initiation, allowed profile field updates, family dashboard, and activity registration workflows belong in tenant-specific public UIs such as TVDK.

Tenant users do not manage tenant config, users, activities, relationships, organizations, registrations, document capabilities, or tenant catalog visibility.

Anonymous User

Anonymous users can call only explicitly public endpoints. The current public flows are tenant auth discovery and tenant-user self-registration when registration is enabled for the tenant.

Public activity registration submission is also anonymous but selects tenant context through the activity and public registration contract rather than through the portal's authenticated tenant header flow.
