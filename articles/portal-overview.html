Portal UI Overview

The Portal UI is the front‑end application of the Organizor platform. It provides the user‑facing interface for authentication, tenant selection, navigation, and all customer‑side functionality.

This document gives a high‑level overview of the Portal UI architecture, its responsibilities, and how it integrates with the backend services.

Purpose of the Portal UI

  • Provide a clean and intuitive interface for end‑users.
  • Handle authentication and session management via Keycloak.
  • Communicate with the Organizor API using secure access tokens.
  • Render tenant‑specific data and enforce authorization rules.
  • Serve as the entry point for all customer‑facing features.

Technology Stack

  • Blazor WebAssembly for client‑side rendering.
  • .NET 10 for the portal runtime and API integration.
  • Keycloak for authentication (OIDC + PKCE).
  • Component‑based architecture for maintainability.

High‑Level Structure

The Portal UI is organized into:

  • Pages — top‑level routes (e.g., /dashboard, /profile)
  • Components — reusable UI building blocks
  • Services — API clients, auth handlers, state management
  • Layouts — shared UI shells (navigation, headers, footers)
  • wwwroot — static assets

Authentication Flow

The Portal UI uses:

  • OIDC Authorization Code Flow with PKCE
  • Keycloak as the identity provider
  • Access tokens for API calls
  • Refresh tokens handled by Keycloak session

Current local configuration:

Setting Value
Portal origin https://localhost:7025
Keycloak authority https://localhost:8443/realms/organizor-dev
Keycloak client organizor-ui
Login callback https://localhost:7025/authentication/login-callback
Logout callback https://localhost:7025/

API Integration

The Portal UI communicates with the Organizor API using:

  • Typed HttpClient instances
  • AuthorizationMessageHandler
  • Automatic token injection
  • Tenant‑aware endpoints

The local portal API client targets https://localhost:7184 and attaches tokens issued by the organizor-dev realm.

See:
API Integration → api-integration.md

Summary

The Portal UI is a modular, secure, and scalable front‑end built on Blazor WebAssembly. It integrates tightly with Keycloak for authentication and the Organizor API for data access, providing a seamless experience for end‑users.
